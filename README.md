## 📌 Project Overview

**Ceylon Railway** is the research showcase for **“AI-Driven Intelligent Railway Operations System,”** developed under SLIIT research group **R26-IT-127**. The research investigates how artificial intelligence, real-time operational information, predictive analytics, and optimization can support more informed decisions in the Sri Lankan railway context.

The overall project is organized into **four individual research components** that address complementary railway challenges: ticket fraud, real-time tracking and delays, scheduling, and passenger demand and capacity.

> **Academic project notice:** This is an academic research project and demonstration website. It is **not** an official Sri Lanka Railways website or a live operational service. Research outputs and performance claims are subject to experimental evaluation.

## 🎯 Research Objectives

- Investigate intelligent methods for identifying suspicious ticket use and supporting risk-aware passenger verification.
- Explore GPS/IoT-informed train tracking and probabilistic delay prediction.
- Study multi-objective optimization for train scheduling and capacity management.
- Investigate spatio-temporal passenger demand forecasting and adaptive seat allocation.
- Communicate project background, methodology, milestones, documents, and research contributions through an accessible website.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vishwaa8/R26-IT-127-Research-Website.git
   ```

2. Open the project folder in **Visual Studio Code**.
3. Ensure the required files are in `assets/`, `documents/`, and `presentations/`.
4. Open `index.html` using the **Live Server** extension, or open it directly in a browser.
5. Test all navigation links, PDF buttons, the Gantt chart, and light/dark mode.

No package installation or build command is necessary.
